About Me

This portfolio was created as part of my self learning process in frontend web development. It shows how I applied core web technologies to produce a working, responsive and visually organised site.

Learning Goal

My goal was to move beyond basic programming knowledge and gain practical experience in building web pages that users can navigate, read and interact with across different screen sizes.

Design Approach
